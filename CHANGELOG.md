# Changelog

All notable changes to `pyev` are documented here. The project follows semantic versioning.

## 0.1.0 - 2026-08-06

- Initial typed, asynchronous broker core.
- Local and bounded-memory engines.
- Routing, middleware, serialization, acknowledgements, retries, circuit breaking, dead letters,
  health reporting, ASGI lifecycle helpers, and portable request/reply.
- Plugin interfaces for third-party engines and optional Redis, RabbitMQ, and Kafka adapters.
